# CS50-Final-Project---A-Samurai-s-Journey
A 2D samurai platformer built in Lua with the LÖVE framework as my CS50x final project. Features multiple levels, sprite animations, and custom collision mechanics.
## How to Run
(You can simply just watch the youtube video demonstration linked in my READ ME if you don't want to do all of this)
1. Download and install the LÖVE framework from https://love2d.org/
2. Download or clone this repository to your computer
3. Open the folder titled "MyPlatformer"
4. Drag the "MyPlatformer" folder onto the LÖVE application icon
5. The game will launch and you can start playing!

### Controls
- WASD or arrow keys to move
- Space or up arrow to jump
- ESC to exit the game
